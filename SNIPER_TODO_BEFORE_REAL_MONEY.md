# Sniper: pendiente antes de usar dinero real

**Obligatorio antes de habilitar dinero real:** implementar y probar un chequeo de venta simulada antes de cada compra. Por ejemplo, solicitar una cotización de venta de Jupiter para el tamaño previsto y bloquear la entrada si no existe una ruta vendible o si el impacto/slippage de salida supera el límite configurado.

Este chequeo no está implementado en esta rama. El bot debe permanecer en paper trading hasta completarlo y validarlo.
